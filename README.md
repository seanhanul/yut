# 증강 윷놀이: 자동차 에디션

브라우저에서 바로 즐기는 윷놀이 게임입니다. 설치와 회원가입 없이 AI 대전이나 친구와의 온라인 대전을 할 수 있습니다.

**바로 플레이:** https://seanhanul.github.io/yut/

## 비상업적 공개

이 게임은 무료로 공개하며, 수익을 받지 않습니다. 광고, 후원, 결제, 방문자 추적 코드가 없습니다.

## 저작권

이 게임에는 저작권이 있습니다. All rights reserved.

이 저장소는 게임을 플레이할 수 있도록 공개한 것으로, 오픈소스 라이선스를 부여하지 않습니다. 저작권자의 허락 없이 복제, 수정, 재배포하거나 상업적으로 이용할 수 없습니다.

## 사용한 외부 구성 요소

- [PeerJS](https://peerjs.com/): 온라인 대전 연결
- [Black Han Sans, Noto Sans KR](https://fonts.google.com/): 화면 글꼴
